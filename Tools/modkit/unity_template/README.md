# Rory's Restaurant Deluxe: Unity port

This Unity project was generated by **RRModKit** (`python rrtool.py unity`) from the original Adobe AIR game.

## Opening it
1. Install **Unity 2021.3 LTS or newer** (2022.3 LTS recommended) with Unity Hub.
2. Unity Hub → **Add** → *Add project from disk* → select this folder → open it.
3. On first import, `Assets/Starlite/Editor/ProjectSetup.cs` creates `Assets/Scenes/Main.unity`, adds it to the
   build settings and sets the player to a resizable 1024×600 window.
4. Press **Play**. The game boots on its own (`GameBootstrap`, `[RuntimeInitializeOnLoadMethod]`) in any scene.

Menu **Rory's Restaurant → Re-run project setup** repeats step 3 if needed.

## What's inside
| Path | Contents |
|---|---|
| `Assets/Game/` | The game logic, ported class-by-class from the decompiled ActionScript 3 (same class and member names). |
| `Assets/Starlite/` | A small Starling 1.x / Flash / TweenLite compatibility layer on top of Unity UI, so the game code reads like the original. |
| `Assets/Resources/RR/` | The game's assets, mirroring the original `data/` folder: decrypted `.ean` textures as PNG, `.eag` backgrounds as JPEG, atlases/level data as XML, MP3 sounds, TTF fonts, and the assets embedded in the SWF under `embedded/`. |
| `Reference/decompiled-as3/` | The decompiled original source, for comparing behaviour. Not compiled. |
| `PORTING.md` | The conventions used to port AS3 to C#. |

## How it works
- **Rendering**: every Starling display object maps to a `RectTransform` under one screen-space canvas. Positions, pivots,
  rotation, alpha and child order follow Starling semantics. The 1024×600 stage is letterboxed to the window.
- **Input**: Starlite does its own hit testing (Starling's `hitTest`, including the pixel-perfect hidden-object picking)
  and dispatches Starling `TouchEvent`s (began/moved/ended/hover) from the mouse.
- **Assets**: `AssetManager.enqueue("data/graphic/hd/kitchen.ean")` loads `Resources/RR/graphic/hd/kitchen`. Atlases
  resolve sprite names exactly like Starling's AssetManager.
- **Saves**: `SharedObject` data is stored as JSON in `Application.persistentDataPath` (`Match3Cooking.json`,
  `Match3CookingSetting.json`). Saves from the Flash version are not imported.
- **Audio**: Flash `Sound`/`SoundChannel` are emulated with pooled `AudioSource`s. Long tracks stream.

## Modding
Edit assets with RRModKit (`RRModKit Editor.bat`), then run `python rrtool.py unity --out <this folder>` again.
That refreshes `Assets/Resources/RR`, `Assets/Game` and `Assets/Starlite`. **Local edits to those script folders are overwritten**,
so keep your own code in a separate folder, such as `Assets/Mods/`.

## Known differences from the AIR original
- Starling filters (`BlurFilter` glows on two effects) are not emulated.
- Text is drawn by Unity's text renderer with the original TTF fonts. Line spacing and kerning can differ slightly.
  Bitmap fonts (Komikandy) use the original glyph atlases.
- Analytics, ads and "more games" links are disabled stubs.
